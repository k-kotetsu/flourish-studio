# Flourish Studio MVP ユーザーフロー

> Version 0.3
> 最終更新：2026-08-07
> 対象範囲は `02_MVP範囲定義/mvp-scope.md` に準拠する

---

## 1. 全体フロー

```text
トップページ（未登録）
  ↓ 「現在地レポートを試す」
現在地レポート開始（ゲストセッション発行）
  ↓
4領域の質問（選択式24問 → AI生成 → 自由記述8問）
  ↓ AI生成
現在地レポート結果（全文を未登録のまま表示）
  ↓ 「ありたい姿を作る」
アカウント登録（ゲストセッションをアカウントへ紐付け）
  ↓
ありたい姿の作成（選択式 → AI対話3往復 → 3案提示・選択・編集 → 確定）
  ↓
最初の領域を選ぶ ──────「あとで」でスキップ可──────┐
  ↓                                                 │
選んだ領域の理想状態と目標を作成                      │
（選択式 → AI対話2往復 → 3案提示・選択・編集 → 目標）  │
  ↓                                                 │
ホーム ←──────────────────────────────────────────┘
  ↓                    ↓
残りの領域を任意で作成    Weekly Reflection（目標1つ以上で実施可能）
```

---

## 2. 基本方針（フロー全体に適用する決定事項）

| 論点 | 決定 |
|---|---|
| アカウント登録のタイミング | 現在地レポートの結果を**全文表示した後**、「ありたい姿を作る」を押した時点で求める |
| 未登録データの置き場所 | サーバーに**ゲストセッション**として保存し、登録時にアカウントへ紐付け直す |
| 保存の粒度 | **確定した成果物だけ**を保存する。入力途中はクライアント側で保持する |
| 途中離脱後の再開 | MVPでは**復帰導線を作らない**。未確定のフローは次回最初からやり直しとする |
| AI生成失敗時 | 自動リトライせず、**即座に再試行ボタン**を表示する。ユーザーの入力内容は保持する |
| 最初に取り組む領域 | Career固定にせず、**ユーザーが4領域から選ぶ**。「あとで」でスキップしてホームへ進める |
| Weekly Reflectionの開始条件 | 目標が**1つ以上**あれば即時実施可能。**回数・頻度の制限なし** |

### 2.1 保存する成果物

サーバーに保存するのは、以下の5つだけとする。

1. 現在地レポートの結果（AI生成が成功した時点）
2. 確定したありたい姿
3. 確定した各領域の理想状態と年間目標（領域ごと）
4. Weekly Reflectionの回答とAIの整理結果
5. アカウント情報

上記以外（質問の途中回答、AI対話の途中ログ、編集中のテキスト）はクライアント側でのみ保持し、離脱時に破棄される。

## 3. 各ステップの詳細

### Step 0：トップページ

| 項目 | 内容 |
|---|---|
| 状態 | 未登録 |
| 表示 | サービス紹介、コピー、「現在地レポートを試す」ボタン |
| 遷移 | ボタンタップで Step 1 へ |

- ここでは登録もログインも求めない。
- 既にログイン済みのユーザーがアクセスした場合はホームへ遷移させる。

---

### Step 1：現在地レポート開始

| 項目 | 内容 |
|---|---|
| 状態 | 未登録（ゲストセッションID発行） |
| 表示 | 所要時間の目安、回答が評価ではないことの説明 |
| 保存 | ゲストセッションIDのみ発行。回答データはまだ保存しない |

---

### Step 2：4領域の質問

以下の2段階で回答する。

1. **選択式の質問（全24問）**：**領域ごとに6問ずつ、4画面に分けて**回答する
   - 領域内の5項目それぞれの充足感（5段階）
   - コミット度1問（5段階）
   - 全6問が必須。未回答があるあいだ次へは進めない
2. **自由記述（全8問）**：各領域につき2問をまとめて回答する
   - 満たされている項目についての問い
   - 満たされていない項目についての問い

自由記述の問いは、**選択式の回答をもとにAIが動的に生成する**。固定文にすると何を書けばよいか伝わりにくいため、選択式で得た情報から、その人にとって具体的な問いを組み立てる。

| 項目 | 内容 |
|---|---|
| 保存 | しない。回答はクライアント側で保持する |
| AI呼び出し | 自由記述の問い文の生成（選択式の回答後、1回） |
| AI失敗時 | 「もう一度生成する」ボタンを表示。選択式の回答は保持される |
| 離脱時 | 回答は破棄される。再訪時はトップページから再開 |

---

### Step 3：現在地レポート結果

| 項目 | 内容 |
|---|---|
| 状態 | 未登録のまま |
| 表示 | あだ名／4領域それぞれの満たされている点・満たされていない点・これからできそうなこと／言語化度・コミット度／次のステップへの締め |
| 保存 | **AI生成成功時点でゲストセッションに保存する** |
| AI呼び出し | 4領域分の現在地フィードバック生成と、言語化度の判定 |
| AI失敗時 | 結果画面に到達させず、生成中画面でエラーと「もう一度生成する」ボタンを表示。Step 2の回答は保持されているため再試行できる |
| 次の導線 | 「ありたい姿を作る」ボタン |

- 結果は出し惜しみせず全文を見せる。
- ここで離脱するユーザーがいることは許容する（プロダクト原則「最初の一歩は小さくする」を優先）。

---

### Step 4：アカウント登録

| 項目 | 内容 |
|---|---|
| 起点 | 結果画面の「ありたい姿を作る」ボタン |
| 処理 | 登録完了時に、ゲストセッションに保存済みの現在地レポート結果をアカウントへ紐付ける |
| 説明文 | 「ここから先は保存されます」といった、登録の理由が伝わる表現にする |
| 中断時 | 登録せず戻った場合、現在地レポート結果はゲストセッションに残るが、復帰導線は作らない |

---

### Step 5：ありたい姿の作成

| Step | 内容 | AI |
|---|---|---|
| 5-1 | 価値観・関心・理想の暮らし方に関する選択式の質問 | なし |
| 5-2 | AIとの自由対話（約3往復） | あり |
| 5-3 | ありたい姿3案の提示 | あり |
| 5-4 | 1案を選択 → 自由に編集 → 確定 | なし |

| 項目 | 内容 |
|---|---|
| 保存 | **5-4で確定した時点でのみ保存する**。選択式の回答と対話ログはクライアント保持 |
| AI失敗時 | 各AI呼び出し箇所で「もう一度生成する」ボタンを表示。それまでの回答・対話内容は保持される |
| 離脱時 | 確定前に離脱した場合、すべて破棄される。再訪時はホームからやり直し |
| 完了後 | Step 6 へ自動遷移 |

- 3案は言い換えではなく、異なる観点を持たせる。
- AIが内部で保持する背景情報の扱いは、確定時の保存対象に含める（詳細設計は別途）。

---

### Step 6：最初の領域を選ぶ

| 項目 | 内容 |
|---|---|
| 表示 | 「どこから育てはじめますか」／4領域をアイコン付きで並べ、1つを選択 |
| 推奨表示 | しない。4領域を体験上も同列に扱い、おすすめや優先度を出さない |
| スキップ | **可能**。「あとで」でホームへ遷移する |
| 完了後 | 選んだ領域で Step 7 へ |

- スキップした場合でも、ありたい姿は保存済みのため、ホームは成果物のある状態で表示される。

---

### Step 7：選んだ領域の理想状態と目標を作成

ありたい姿と同じ流れで作成する。

| Step | 内容 | AI |
|---|---|---|
| 7-1 | その領域についての選択式の質問（3問） | なし |
| 7-2 | AIとの自由対話（約2往復） | あり |
| 7-3 | 理想状態3案の提示（深める／変える／広げる） | あり |
| 7-4 | 1案を選択 → 自由に編集 | なし |
| 7-5 | 年間目標を1〜3個入力 → 確定 | 任意（AIヒント） |

| 項目 | 内容 |
|---|---|
| 保存 | **7-5で確定した時点で、理想状態と目標をまとめて保存する** |
| AIヒント | 目標が思いつかないとき、任意で候補3つを表示できる。押さなければAIは動かない |
| AI失敗時 | 各AI呼び出し箇所で「もう一度生成する」ボタンを表示。それまでの回答・対話内容は保持される |
| 離脱時 | 確定前に離脱した場合、すべて破棄される |
| 完了後 | ホームへ遷移 |

- 3案は言い換えではなく、深める／変える／広げるの3方向で差をつける。
- 上部に確定済みの「ありたい姿」を常時表示し、つながりが切れないようにする。

---

### Step 8：ホーム

| 表示要素 | 内容 |
|---|---|
| ありたい姿 | 確定済みのありたい姿を表示 |
| 4領域 | アイコン＋英語ラベルで Career / Financial / Physical / Social を表示 |
| 領域の状態 | 作成済み領域は閲覧画面への導線、未作成領域は「これから育てる」表現 |
| Weekly Reflection | 導線を表示（下記の条件で有効／無効が切り替わる） |
| Knowledge / Support Tools | 導線のみ表示し、準備中とする |

#### Weekly Reflection導線の状態

| 目標の数 | 導線の状態 |
|---|---|
| 0個 | **表示するが無効状態**。「目標を1つ作ると振り返れるようになります」と添える |
| 1個以上 | 有効。タップで Step 10 へ |

- 未作成領域は「空欄」「未完成」と表現しない。
- ログイン後の着地点は常にホームとする（復帰導線は設けない）。

---

### Step 9：残りの領域を任意で作成・編集

| 項目 | 内容 |
|---|---|
| 起点 | ホームの領域カード |
| 未作成の領域 | Step 7 と同じフロー（選択式 → AI対話 → 3案 → 編集 → 目標） |
| 作成済みの領域 | まず閲覧画面を表示する |
| 順序 | 自由。4領域を一度に完成させることを求めない |
| 保存 | 領域ごとに、確定時に保存 |

#### ありたい姿の編集

ホームのありたい姿カードから閲覧画面へ入り、2つの経路を用意する。

| 経路 | 用途 |
|---|---|
| 「編集する」 | 一文を直接書き換える。**AI対話を経由しない** |
| 「AIと話して作り直す」 | 選択式からフローをやり直す |

**ありたい姿を変えても、既存の理想状態と目標は残す。** 作り直すかは領域ごとにユーザーが判断する。

#### 作成済み領域の編集

閲覧画面から2つの経路を用意する。

| 経路 | 用途 |
|---|---|
| 「編集する」 | 理想状態と目標を直接書き換える。**AI対話を経由しない** |
| 「AIと話して見直す」 | 選択式からフローをやり直し、理想状態を作り直す |

誤字の修正や目標の追加のために、毎回AI対話を通させない。

---

### Step 10：Weekly Reflection

| 項目 | 内容 |
|---|---|
| 実施条件 | 目標が1つ以上登録されていること |
| 頻度制限 | **なし**。いつでも何度でも実施できる |
| 入力1 | 登録されている各目標の3段階評価（選択式） |
| 入力2 | 自由記述欄1つ（任意入力、全体で1つのみ） |
| AI呼び出し | 全体に対して1つのフィードバック（振り返り・気づき・次の一歩） |
| AI失敗時 | 「もう一度生成する」ボタンを表示。評価と自由記述は保持される |
| 保存 | **AI生成が成功し、結果を表示した時点で回答とAI出力をまとめて保存する** |
| 離脱時 | 保存前の離脱は破棄される |
| 完了後 | ホームへ戻る |

- 頻度を制限しないため、UI上は「今週の振り返り」と限定表記せず、回答日時とともに記録する。
- MVPでは過去の回答一覧・時系列分析は表示しない（`mvp-scope.md` の対象外項目）。

## 4. AI呼び出し箇所の一覧

| # | 箇所 | 失敗時の挙動 | 保持されるもの |
|---|---|---|---|
| 1 | 現在地レポートの自由記述の問い生成 | 再試行ボタン | 選択式24問の回答 |
| 2 | 現在地フィードバックの生成（4領域） | 再試行ボタン | 選択式と自由記述の回答 |
| 3 | ありたい姿のAI対話（約3往復） | 再試行ボタン | それまでの対話内容 |
| 4 | ありたい姿3案の生成 | 再試行ボタン | 選択式の回答と対話内容 |
| 5 | 領域のAI対話（約2往復） | 再試行ボタン | それまでの対話内容 |
| 6 | 領域の理想状態3案の生成 | 再試行ボタン | 選択式の回答と対話内容 |
| 7 | Weekly Reflectionの整理 | 再試行ボタン | 3段階評価と自由記述 |

上記に加えて、**任意で発生する呼び出し**が1つある。

| # | 箇所 | 発生条件 |
|---|---|---|
| 任意 | 年間目標のAIヒント | ユーザーが「AIにヒントをもらう」を押したときのみ |

共通ルール：

- 自動リトライは行わない。
- 失敗してもユーザーの入力は必ず画面上に保持する。
- 定型文でのフォールバックはしない（ユーザーの言葉を扱う機能であるため）。

## 5. 保存タイミングの一覧

| タイミング | 保存されるもの | 保存先 |
|---|---|---|
| 現在地レポートのAI生成成功時 | 4領域の回答とレポート結果 | ゲストセッション |
| アカウント登録完了時 | 上記をアカウントへ紐付け | アカウント |
| ありたい姿の確定時 | ありたい姿と背景情報 | アカウント |
| 各領域の目標確定時 | 理想の状態と年間目標（1〜3個）をまとめて | アカウント |
| 領域の編集画面での保存時 | 書き換えた理想の状態と目標 | アカウント |
| Weekly Reflectionの結果表示時 | 3段階評価、自由記述、AI出力 | アカウント |

上記以外のタイミングでは保存しない。

## 6. このフローで未決の事項

すべて決着済み。全体の未決は定義書19章にまとめている。

| 旧・未決 | 決定 |
|---|---|
| ゲストセッションの保持期間 | 30日。期限切れ時は S-01 へ戻す |
| アカウント登録の方式 | メール＋パスワード と Google |
| 領域フローが4領域分繰り返される負荷 | 「1セッション＝1領域」と定義し直した（定義書 8.3） |
| Weekly Reflection の回答負担 | 3段階を横並びセグメントにして1目標3行に圧縮 |
| 未作成領域の文言 | 「これから育てる領域」 |
| 3段階評価のラベル | 進んでいる／止まっている／見直したい |
