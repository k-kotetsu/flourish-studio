## MVPのゴール

ユーザーが以下を一通り体験できる状態を作る。

1. 現在地レポートで「今の自分」を気軽に知る
2. AIとの対話を通じて「ありたい姿」を言葉にする
3. 4領域（Career / Financial / Physical / Social）の理想状態と年間目標を設定し、Flourish Mapとしてつなげる
4. 週に一度のWeekly Reflectionで、目標の進み方を振り返り、次の一歩を見つける
5. ホーム画面で、ありたい姿と4領域のつながりを俯瞰する

MVPで検証したいのは、**「現在地レポート → ありたい姿 → Flourish Map → Weekly Reflection」という一連の体験が、ユーザーにとって価値として成立するか**という点である。

---

## 対象範囲（このMVPに含むもの）

### 1. 現在地レポート
- 4領域の選択式質問（領域ごとに5項目の充足感5段階＋コミット度1問、計24問）
- 各領域の自由記述2問（選択式の回答をもとにAIが動的生成）
- AIによる現在地フィードバック（あだ名／満たされている点・満たされていない点／これからできそうなこと）
- 言語化度・コミット度の2軸での表現

### 2. ありたい姿の作成
- 価値観・関心・理想の暮らし方に関する選択式の質問
- AIとの約3往復の自由対話
- ありたい姿3案の提示・選択・編集・確定

### 2-b. ありたい姿の閲覧・編集
- 確定後の閲覧画面
- 直接編集と、AIと話して作り直す2つの経路

### 3. 4領域の理想状態
- 最初に取り組む領域をユーザーが4領域から選択
- 選択式の質問、AIとの約2往復の対話、理想状態3案の提示・選択・編集（ありたい姿と同じ流れ）
- Career・Financial・Physical・Social、それぞれの理想状態の作成
- 各領域は独立して作成・編集可能（4領域同時完成を求めない）
- 作成済み領域の閲覧と、AI対話を経由しない直接編集

### 4. 各領域1〜3個の年間目標
- 各領域の目標を1〜3個の範囲で任意に設定
- 目標はありたい姿・理想状態につながっている必要がある
- 手が止まったとき用のAIヒント（任意）

### 5. Flourish Map
- ありたい姿・4領域の理想状態・年間目標をひとつにまとめた構造の表示
- 未作成領域は「空欄」ではなく「これから育てる領域」として表現

### 6. Weekly Reflection
- 各目標の3段階評価
- 課題を入力する自由記述欄1つ（4領域まとめて1つ、任意入力）
- AIによる「振り返り・気づき・次の一歩」の整理

### 7. 公開サイト（LP・記事）
- トップページ（LP）：7セクションの縦長構成
- 記事一覧：カテゴリは4領域＋「Flourishとは」
- 記事詳細：末尾に共通のCTAバナー
- ログイン不要で全文を読める

### 8. ホーム画面
- ありたい姿の表示
- アイコンを用いた4領域の表示
- Flourish MapとWeekly Reflectionへの導線

## 対象外（MVPに含めないもの）

- **アプリ内のKnowledgeレコメンド**：Flourish Mapの内容に応じた記事の出し分け。ホーム画面に導線のみ表示し、準備中とする
  - **公開サイトの記事一覧・記事詳細はMVPに含む**（上記7）。同じ記事を使い、出し分けだけを後回しにする
- **Support Tools**：ホーム画面に導線のみ表示し、準備中とする
- **通知**：Weekly Reflectionの曜日・時刻固定通知は含めない
- **シェア機能**：現在地レポートのシェア機能は含めない
- **詳細な履歴**：過去バージョンの比較・詳細な履歴表示は含めない

これらはMVPリリース後の利用状況を踏まえて順次検討する。
