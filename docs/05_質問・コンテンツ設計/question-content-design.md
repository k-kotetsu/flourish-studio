## 1. 設計方針

| 方針 | 内容 |
|---|---|
| 評価しない | 点数や優劣を示さず、状態の違いとして表現する |
| 言葉を奪わない | 選択肢はユーザーの状態を代弁するに留め、結論を与えない |
| 満足も扱う | 満たされていない点だけでなく、満たされている点も同じ重さで扱う |
| 入口は軽く | 結果画面はまずエンタメとして楽しめる形で入り、そこから中身に降りていく |
| 領域名の扱い | 設問文では Career / Financial / Physical / Social の英語表記に日本語の補足を添える |

## 2. 現在地レポート：選択式（S-12）

各領域につき、**充足感5項目＋コミット度1問＝6問**。4領域で**計24問**。1画面にスクロール表示する。

### 2.1 設問の構造

| # | 測るもの | 形式 |
|---|---|---|
| Q1〜Q5 | 領域内の5項目それぞれの充足感 | 5段階・単一選択（項目ごと） |
| Q6 | コミット度（より良くするために動けているか） | 5段階・単一選択 |

領域全体の充足感は、Q1〜Q5の平均として算出する（独立した設問は設けない）。

### 2.2 充足感の選択肢（全項目共通）

設問文：「**{領域}** について、それぞれ今どのくらい満たされていますか？」

**画面上は左から右へ、この順で並べる。右にいくほどポジティブ。**

| 並び | 選択肢 | スコア |
|---|---|---|
| 左端 | 満たされていない | 0 |
| | あまり満たされていない | 1 |
| 中央 | どちらとも言えない | 2 |
| | まあ満たされている | 3 |
| 右端 | 満たされている | 4 |

- 目盛りの両端にのみラベルを表示し、5段階すべてに全文ラベルは付けない（縦が約3倍になるため）
- 導入文に「右にいくほど、満たされている状態です」を添えて、向きを明示する
- 逃げ道の選択肢は設けない。判断がつかない場合は「どちらとも言えない」を選ぶ

### 2.3 領域ごとの5項目

#### Career（仕事・働き方）

| # | 項目 |
|---|---|
| 1 | 仕事のやりがい |
| 2 | スキルや成長の実感 |
| 3 | 今後のキャリアの見通し |
| 4 | 収入や待遇 |
| 5 | 働き方や時間の使い方 |

職場の人間関係は Social と重複するため、Career には含めない。

#### Financial（お金・生活設計）

| # | 項目 |
|---|---|
| 1 | 貯蓄の状況 |
| 2 | 収入の水準 |
| 3 | 支出の把握とコントロール |
| 4 | 将来に向けた資産形成 |
| 5 | 生活費や返済の負担 |

#### Physical（健康・生活習慣）

| # | 項目 |
|---|---|
| 1 | 睡眠 |
| 2 | 運動する習慣 |
| 3 | 食事 |
| 4 | 体調や疲れのとれ方 |
| 5 | 体重や体型 |

心理面（気分の浮き沈み）は、定義書 5章の Physical の定義に含まれないため項目から外した。

#### Social（人との関係）

| # | 項目 |
|---|---|
| 1 | 気軽に話せる相手がいること |
| 2 | 家族やパートナーとの関係 |
| 3 | 友人と過ごす時間 |
| 4 | 職場以外のつながり |
| 5 | 頼れる人がいるという安心感 |

### 2.4 Q6：コミット度（4領域共通）

設問文：「**{領域}** をより良くするために、いま動けていますか？」

選択肢の文が長いため、目盛りではなく縦積みで表示する。**充足感と向きを揃え、下にいくほどポジティブにする。**

| 並び | 選択肢 | スコア |
|---|---|---|
| 上 | まだこれからのところ | 0 |
| | あまり動けていない | 1 |
| | 動けている時と、そうでない時がある | 2 |
| | 少し動けている | 3 |
| 下 | しっかり動けている | 4 |

## 3. 現在地レポート：自由記述（S-14）

各領域につき**2問**、計8問。問い文は**選択式の回答をもとにAIが動的生成する**。

### 3.1 問いの設計

領域ごとに、選択式の5項目から2つを選んで問いを組み立てる。

| 問い | 対象 | 聞くこと |
|---|---|---|
| 問い1 | その領域で**最も充足感が高い**項目 | いまどんな状況か、なぜそう感じるのか |
| 問い2 | その領域で**最も充足感が低い**項目 | いまどう感じているか、これからどうしていきたいか |

### 3.2 生成テンプレート

**問い1（満たされている項目について）**

> {領域}の中では「{項目名}」が満たされているようですね。いまどんな状況で、なぜそう感じているのか、書ける範囲で教えてもらえますか。

**問い2（満たされていない項目について）**

> 一方で「{項目名}」は、少し気になっているようですね。いまどう感じていて、これからどうしていきたいですか。

### 3.3 例外パターン

| 状況 | 問いの切り替え |
|---|---|
| 5項目すべてが高い（3以上） | 問い2を「あえて挙げるとすれば『{最も低い項目}』でしょうか。ここについて、思うところはありますか。」に切り替える |
| 5項目すべてが低い（1以下） | 問い1を「この中では『{最も高い項目}』が比較的まだ保たれているようです。どんな状況ですか。」に切り替える |
| 同スコアが複数 | 項目の並び順が先のものを優先する |
| 5項目すべてが同スコア | 項目1を問い1、項目5を問い2の対象とする |

### 3.4 入力の必須／任意

- **すべて任意入力**とする。
- 全問空欄の場合、言語化度は最下段階として扱い、空欄であることを責めない表現にする。

### 3.5 AI生成のルール

- 問い文にユーザーへの評価を含めない（「よくできていますね」等を書かない）
- 項目名は選択式で提示した表記をそのまま使い、言い換えない
- 1問は2文以内に収める
- 答えを誘導する例示を入れない

## 4. 言語化度・コミット度の算出

### 4.1 コミット度（選択式から算出）

Q6のスコア（0〜4）を4領域分合計する。**満点16点。**

| 合計スコア | 段階 |
|---|---|
| 0〜3 | 種 |
| 4〜7 | 芽 |
| 8〜11 | 苗 |
| 12〜16 | 木 |

### 4.2 言語化度（AIが自由記述から判定）

AIが自由記述8問を読み、以下の観点で判定する。

| 観点 | 見るもの |
|---|---|
| 自分の言葉か | 一般論や借り物の言葉ではなく、その人の状況が書かれているか |
| 具体性 | 場面や出来事が含まれているか |
| 理由 | なぜそう感じるのかまで書かれているか |
| 分量 | 書ける状態にあったか |

段階は **種 / 芽 / 苗 / 木** の4段階とする（定義書 7.6 で確定）。

#### 段階ごとの基準

| 段階 | 状態 |
|---|---|
| **種** | ほとんど書かれていない、または一般論に留まる。「忙しい」「不安」など、誰にでも当てはまる語で終わっている |
| **芽** | 自分の状況が書かれている。ただし理由や場面までは書かれていない |
| **苗** | 具体的な場面や出来事が書かれ、なぜそう感じるかにも触れている |
| **木** | 場面・理由・自分なりの解釈まで書かれ、8問を通して言っていることに一貫性がある |

**分量だけで判定しない。** 短くても場面と理由が書かれていれば苗以上とする。長くても一般論の繰り返しなら種のままとする。

## 5. 現在地レポート：AI出力（S-15 → S-16）

### 5.1 画面の構成

上から順に、以下を出力する。

| # | ブロック | 性質 |
|---|---|---|
| 1 | **あだ名**「今のあなたを一言で表すなら」 | エンタメ。軽く、笑える |
| 2 | 領域ごとの整理（4領域分） | 満たされている点／満たされていない点／これからできそうなこと |
| 3 | 言語化度・コミット度 | 現在の段階 |
| 4 | 締め | 次のステップへの訴求 |

**軽い入口から入り、下に降りるほど真面目になる構成**とする。最初から丁寧な分析を並べない。

### 5.2 あだ名

#### 表示

一文の中にあだ名を置き、**あだ名だけを大きく強調する**。

> 今の状態のあなたを、あえて一言で表すと
>
> # 助走長めのアップデーター
>
> でしょうか。

直下に、小さく補足を添える。

> ※ あくまで参考です。これがあなたを表すものではありません。

#### 生成ルール

| ルール | 内容 |
|---|---|
| 形式 | 10〜20文字程度。名詞句、または短い言い切り |
| 禁止形式 | **「〜人」「〜タイプ」で終える形にしない**（説明的で面白くならない） |
| トーン | クスッとする程度。SNS診断のようにふざけすぎない |
| 手法 | 対比・ずれ・比喩を使う。領域間のスコア差が大きいほど効く |
| 対象 | 状態を言い表す。能力・人格・容姿を評価しない |
| 禁止 | 「ダメ」「残念」などの否定語。収入の多寡や病気そのものを笑いの対象にしない |
| 分量 | 1つのみ。説明を添えない（説明は下の領域別ブロックが担う） |

#### 出力例

| 回答の傾向 | あだ名 |
|---|---|
| Career高・Financial低 | 全速前進、燃料計は未確認 |
| Financial高・Career低 | 貯金は順調、人生は保留 |
| Social高・Physical低 | まわりは充電、自分は放電 |
| Physical高・Social低 | からだは絶好調、予定表は空欄 |
| 全体的に低い | 人生ちょいメンテ中 |
| 全体的に高い | 充実、ただし自覚なし |
| コミット度高・充足感まちまち | やる気はある、作戦はこれから |
| 特定領域だけ極端に低い | ほぼ順調、一箇所だけ工事中 |
| 充足感中庸・コミット度低 | 助走長めのアップデーター |

### 5.3 領域ごとの整理

4領域それぞれについて、3ブロックを出力する。

| ブロック | 内容 |
|---|---|
| 満たされている点 | 高スコアの項目と、自由記述の問い1の回答を踏まえた一文 |
| 気になっている点 | 低スコアの項目と、自由記述の問い2の回答を踏まえた一文 |
| これからできそうなこと | 気になっている点に対する、小さく具体的な次の一歩 |

見出しは「満たされていない点」ではなく**「気になっている点」**とする。欠けているものを数える見出しにしない。

**満足と不満を必ず両方書く。** 課題だけを並べた出力にしない。

### 5.4 「これからできそうなこと」の生成ルール

| ルール | 内容 |
|---|---|
| 紐づけ先 | その領域で最も満たされていない項目 |
| 優先材料 | 自由記述の問い2でユーザーが書いた「どうしていきたいか」を最優先で反映する |
| 個数 | 1領域につき1つだけ。複数出して選ばせない |
| 粒度 | 今週から始められる大きさにする |
| 語尾 | 「〜すべき」ではなく「〜から始めてみるのはどうでしょう」 |
| 禁止 | 商品・サービスの購入や契約を伴う提案をしない |
| 禁止 | 問題そのものを解決しきる提案をしない。最初の一歩に留める |

#### 出力例

> **これからできそうなこと**
> まずは1週間だけ、何にいくら使ったか眺めてみるのはどうでしょう。減らすことは、そのあとで考えれば大丈夫です。

> **これからできそうなこと**
> 寝る時間を早めるより先に、起きる時間をそろえるほうが、案外続きやすいかもしれません。

### 5.5 締め

課題を眺めて終わりにせず、次のステップへ強く誘導する。

> ここまでは、いまの自分をそっと眺めてみた時間でした。
>
> 気になっていることは、そのままにしておくと、来年も同じ場所で待っていることが多いものです。動きはじめられるのは、それが「自分にとってなぜ大事なのか」とつながったときかもしれません。
>
> Flourish Mapでは、仕事も、お金も、からだも、人とのつながりも、バラバラの悩みとしてではなく、ひとつの「ありたい姿」につなげて考えていきます。4つがつながったとき、進み方が変わっていきます。
>
> 次は、あなたが3〜5年後にどうありたいか。一緒に言葉にしていきましょう。

ボタン：**ありたい姿を作る**

### 5.6 出力ルール

- 領域ごとの整理では断定しない（「〜ですね」「あなたは〜な人です」を使わない）
- ユーザーが使った言葉をできる限りそのまま返す
- 満たされている項目を「現状維持でよい」と片付けない
- 広告や商品購入への誘導を混ぜない

### 5.7 プロダクト原則との関係

あだ名とアドバイスは、定義書の以下の記述に対する**意図的な例外**である。

| 定義書の記述 | 例外の扱い |
|---|---|
| 7.5「断定的に評価するのではなく」 | あだ名はエンタメとして言い切る。ただし「〜でしょうか」と問いかけの形に収め、直下に「これがあなたを表すものではありません」を必ず添える |
| 7.7「問題の解決まで行わず、気づきの段階で止める」 | 「これからできそうなこと」は最初の一歩に限定する。問題を解決しきる提案はしない |
| 14.2「〜ですねと決めつける表現を避ける」 | あだ名ブロックのみ適用外。領域ごとの整理には従来どおり適用する |

定義書 7.5 / 7.7 は本書の内容に合わせて更新済み（Version 0.5）。

## 6. ありたい姿：選択式質問（S-31）

3問構成。

### Q1：これからの3〜5年で、大切にしたいことは？（3つまで選択）

成長 ／ 安定 ／ 自由 ／ つながり ／ 挑戦 ／ 貢献 ／ 自分らしさ ／ 誠実さ ／ 学び ／ 健康 ／ 余白 ／ 家族

### Q2：満たされていると感じるのは、どんなときですか？（複数選択）

1. 誰かの役に立てたと感じたとき
2. 新しいことができるようになったとき
3. 自分で決められたと感じたとき
4. 大切な人と過ごしているとき
5. 落ち着いた生活が送れているとき
6. 集中して何かに取り組めたとき
7. 認められたと感じたとき
8. まだよくわからない

### Q3：3〜5年後、どんな毎日を送っていたいですか？（1つ選択）

1. 今の延長線上で、より満足できている
2. 今とは違う場所や働き方をしている
3. 選択肢を持てる状態になっている
4. 大切な人との時間が確保できている
5. 心身に余裕がある
6. まだ想像がつかない

領域を選ばせる設問は置かない。ありたい姿は領域横断の概念であり、最初に取り組む領域は S-50 で別途選ぶため。

## 7. ありたい姿：AI対話（S-32）

約3往復。1回の返答は「受け止める一文＋問い1つ」で構成する。

| 往復 | 目的 | 問いの方向 |
|---|---|---|
| 1回目 | 選んだ価値観の背景を引き出す | 選択式で最も特徴的だった回答を取り上げ、なぜそれを選んだのかを聞く |
| 2回目 | 具体的な場面に降ろす | それを感じた実際の経験や場面を聞く |
| 3回目 | 将来につなげる | その感覚が3〜5年後にどうなっていてほしいかを聞く |

### 対話ルール

- 「〜ですね」と決めつけない
- ユーザーが使った言葉をそのまま返す
- ユーザーの価値観や結論をAIが置き換えない
- 答えを提示せず、問いで返す

### 承認の入れ方

ラポールを作るため、承認は**意図的に入れる**。ただし条件をつける（定義書 14.3）。

| ルール | 内容 |
|---|---|
| 対象 | 人格や能力ではなく、**言葉にできたことや実際に取った行動**を認める |
| 方法 | ユーザーが書いた言葉を引用したうえで、どこが良かったのかを示す |
| 終わり方 | 承認だけで返答を終えない。必ず問いか次につなげる |
| 頻度 | 毎回褒めない。3往復のうち1〜2回に留める |
| 前提 | 書かれていないことを褒めない。程度を誇張しない |

| 避ける | 望ましい |
|---|---|
| 素晴らしいですね。 | 「まわりが安心して力を出せるように」と書かれていました。ここは自分の言葉になっていると思います。それはどんな場面で感じたことですか。 |
| よく考えられていますね。 | 迷っていると書きながら、選ばなかった理由まで書かれていました。何がそう思わせたのでしょう。 |

### 初回の起点となる文（例）

> 「{選んだ価値観}」を選ばれていました。これを選んだのは、何か思い当たることがありましたか。

## 8. ありたい姿：3案の生成（S-33 → S-34）

### 8.1 差別化の軸

3案は**向かう先の広さ**で分ける。この軸を固定することで、3案が言い換えにならないことを構造で担保する。

| 案 | 向かう先 | 性質 |
|---|---|---|
| 案1 | 自分の内側 | 自分がどうありたいか |
| 案2 | 身近な他者 | 周囲の人との関係の中でどうありたいか |
| 案3 | より広い社会 | 社会や世の中に対して何をしたいか |

### 8.2 出力形式

- 原則として**一文**
- 「〜でありたい」「〜していきたい」の形を基本とする
- 各案に、その案がどの方向を向いているかを示す短いラベルを添える

### 8.3 出力例

| 案 | ラベル | 文 |
|---|---|---|
| 案1 | 自分の納得を軸に | 自分で選んだと言えることを積み重ねて生きていきたい。 |
| 案2 | まわりの人とともに | まわりの人が安心して力を出せる存在でありたい。 |
| 案3 | もっと広く | 人の可能性が広がる場をつくっていきたい。 |

### 8.4 3案提示時の文言

> どれが正解ということはありません。いちばん自分に近いと感じたものを選んでください。あとから自由に書き換えられます。

## 9. 領域の理想状態・年間目標（S-50 〜 S-56）

ありたい姿と同じ流れで作成する。選択式 → AI対話2往復 → 3案提示 → 編集・確定 → 年間目標。

### 9.1 最初の領域を選ぶ（S-50）

オンボーディングでは、最初に取り組む領域をユーザー自身が選ぶ。Career固定にしない。

> どこから育てはじめますか。ひとつだけ選んでください。あとから他の領域も作れます。

4領域をアイコン付きで並べ、いずれか1つを選択する。「あとで」でスキップしてホームへ進める。

推奨や優先度の表示はしない（4領域を体験上も同列に扱うため）。

### 9.2 領域の選択式質問（S-51）

3問構成。領域ごとに設問文の領域名だけが変わる。

確定した「ありたい姿」を画面上部に常に表示し、つながりが見えるようにする。

**Q1：{領域}の中で、3〜5年後にいちばん変わっていてほしいのはどれですか？（1つ選択）**

### 9.3 領域のAI対話（S-52）

約2往復。ありたい姿の対話（7章）と同じルール・同じ承認の入れ方を適用する。

| 往復 | 目的 | 問いの方向 |
|---|---|---|
| 1回目 | 大切にしたいことの背景を引き出す | Q1で選んだ項目と、Q2で選んだ「大切にしたいこと」を結びつけ、なぜそれが自分にとって大事なのかを聞く |
| 2回目 | ありたい姿につなげる | Q3で選んだ位置づけを踏まえ、それが実現したとき確定済みの「ありたい姿」にどう近づくのかを聞く |

### 9.4 理想状態の3案（S-53 → S-54）

3案は**深める／変える／広げる**の3方向で差をつける。ありたい姿の3案（自分／他者／社会）とは別の軸を使う。

| 案 | 方向 | 意味 |
|---|---|---|
| 案1 | 深める | 今あるものの質を上げる |
| 案2 | 変える | やり方や進め方を変える |
| 案3 | 広げる | 新しい場所や関係に出ていく |

3案の順序は固定とし、ユーザーの回答で並べ替えない。どの方向にも等しく可能性があることを示すため。

Q2（大切にしたいこと）とQ3（人生の中での位置づけ）は、各案の**中身を作る材料**として使う。3案すべてに、選ばれた価値観と位置づけが反映されている必要がある。

#### 出力形式

- 1年後の状態として、原則1〜2文
- 「〜になっている」「〜できている」の形を基本とする
- 各案に方向を示す短いラベルを添える

#### 出力例（Career・「キャリアの見通し」を選択した場合）

| 案 | ラベル | 文 |
|---|---|---|
| 案1 | 今の場所で深める | 今の仕事の中で自分の強みが言葉になっていて、次に何を任されたいかを自分から言えている。 |
| 案2 | やり方を変える | 働き方や役割を一度組み替えて、自分に合う進め方が見つかっている。 |
| 案3 | 外に出る | 社外の人と接点があり、今の会社の外でも通用する選択肢を持てている。 |

### 9.5 理想状態の編集・確定（S-55）

- 選んだ案を自由に編集できる
- 上部に「ありたい姿」を表示し続け、つながりが切れないようにする
- ありたい姿の一文は**上限60文字、推奨40文字以内**（定義書 9.4）

### 9.6 年間目標（S-56）

> その状態に近づくために、今年取り組むことを書いてください。（1〜3個）

- ユーザーが自分で書く。**AIは自動で提案しない**
- 2個目以降は「＋ 目標を追加」で任意に増やす
- 無理に3個作らせない。1個で確定できる

#### AIヒントボタン

手が止まったとき用に、任意で押せるボタンを置く。

> 思いつかないときは [ AIにヒントをもらう ]

- 押したときのみ、理想状態に基づく候補を3つ表示する
- 候補はそのまま採用でき、編集もできる
- 画面遷移せず、**画面内のローディング**で表示する（生成中画面を挟まない例外）
- 候補は「例」として示し、そのまま使うことを勧める文言は置かない

### 9.7 閲覧と編集（S-57 / S-58）

作成済みの領域をホームから開いた場合は、**閲覧専用画面**（S-57）を表示する。

## 10. Weekly Reflection（S-61 → S-63）

### 10.1 3段階評価のラベル

目標を主語にした短い表現とする。ユーザー自身を採点する形にしない。

| ラベル | 意味 |
|---|---|
| 進んでいる | 前に進んでいる |
| 止まっている | 動きがなかった |
| 見直したい | 目標そのものを変えたい |

各目標の上に、所属する領域名を表示する。

### 10.2 自由記述の問いかけ

全体で1つだけ設ける。任意入力。

> 今週、目標を進めるうえで困ったことや、気になったことがあれば教えてください。

### 10.3 AI出力の構成

3要素を、この順で1つのまとまりとして返す。

| 要素 | 内容 | 分量の目安 |
|---|---|---|
| 振り返り | 今週どのような動きがあったか | 2〜3文 |
| 気づき | 目標の進み方や課題から見える傾向 | 2〜3文 |
| 次の一歩 | 翌週に取り組める、小さく具体的な行動 | 1つだけ提示 |

### 10.4 出力ルール

- 領域ごとに4つのコメントを返さず、**全体に対して1つ**返す
- 「止まっている」を否定的に扱わない
- 「見直したい」が選ばれた目標は、変えることを肯定的に受け止める
- 次の一歩は必ず1つに絞る。複数提示して選ばせない
- ユーザーを評価する語（頑張っていますね、素晴らしい）を使わない
