## 2. S-12 選択式（領域ごと・6問）

**4領域共通の1画面とし、領域をパラメータで切り替える。** 同じ画面を4回通ることになる。

| 項目 | 内容 |
|---|---|
| 型 | フォーム |
| ヘッダー | × 中断＋プログレス（領域に応じて 1〜4 / 6） |
| 構成 | 充足感5項目＋コミット度1問＝6問 |
| スクロール | 1画面はほぼ1スクリーンに収まる |

### 要素

| # | 要素 | 役割 | 有効・無効の条件 |
|---|---|---|---|
| 1 | 領域見出し | いまどの領域を答えているかを示す | 常時表示 |
| 2 | 導入文 | 深く考えこまなくてよいことを伝える | 常時表示 |
| 3 | 充足感の目盛り（5問） | 5段階・単一選択。両端にのみラベル。**右がポジティブ** | 常時操作可 |
| 4 | コミット度の選択肢（1問） | 5段階・単一選択。文が長いため縦積み。**下がポジティブ** | 常時操作可 |
| 5 | 「次へ」 | 次の領域、または S-13 へ | **未回答が1問でもあれば無効** |
| 6 | ボタン直下の補足 | 無効の理由を伝える | 未回答があるときのみ表示 |

**全6問が必須。** 未回答のまま次へ進むことはできない。充足感の平均を項目単位で算出するため、欠損があると領域間の比較が成立しなくなる。

### 状態

| 状態 | 表示 |
|---|---|
| 未回答あり | 「次へ」は無効。直下に「すべて選ぶと、次に進めます」を表示 |
| 全問回答済み | 「次へ」が有効。補足は消える |
| 中断確認 | ダイアログ（1.2参照） |

### 遷移

| 操作 | 遷移先 |
|---|---|
| 次へ（Career / Financial / Physical） | 次の領域の S-12 |
| 次へ（Social） | S-13（問い生成中） |
| × 中断 → やめる | S-01 トップページ |
| × 中断 → つづける | 同じ画面に留まる |

### 要素

| # | 要素 | 役割 | 備考 |
|---|---|---|---|
| 1 | あだ名ブロック | エンタメとして入口を軽くする | 「〜でしょうか。」で問いかけに収める |
| 2 | 免責の一文 | 決めつけからの逃げ道 | **省略不可**。あだ名と必ずセット |
| 3 | 領域別ブロック（4回） | 満たされている点／気になっている点／これからできそうなこと | 3つとも省略しない |
| 4 | 言語化度・コミット度 | 現在の段階 | **4段階すべてを並べ、該当する段階だけを塗る**（下記参照） |
| 5 | 締め | 次のステップへの訴求 | カードに入れず地の文にする |
| 6 | 「ありたい姿を作る」 | S-21へ | 常時有効 |

### 成長段階の表示

段階名だけを1つ示しても、それが4段階のどこなのかが伝わらない。**種・芽・苗・木の4つをすべて横に並べ、該当する段階だけをアクセント色で塗る。**

| 要素 | 内容 |
|---|---|
| 軸名 | 言語化度 ／ コミット度 |
| 軸の説明 | 各軸に1行添える（例：「自分の考えが、どのくらい自分の言葉になっているか」） |
| 段階 | 種 → 芽 → 苗 → 木 の4つを等幅で並べる |
| アイコン | **線画で描き起こす**（デザイン原則 7.6）。4つ並べて成長の連続が読み取れること |
| 現在位置 | アイコンと段階名をアクセント色で塗り、段階名を太字にする |
| 数値 | **出さない**（スコアや点数は表示しない） |

### 状態

状態バリエーションなし。AI生成が成功した場合のみ到達する画面のため。

#### 7.1.1 S-01 トップページ（LP）

**アプリ画面ではなくウェブサイトとして構成する。** 唯一、他の26画面と設計の性格が異なる画面。

| 項目 | 内容 |
|---|---|
| ヘッダー | サービス名（左）＋ **ログイン**（右）。固定 |
| 本体 | 7セクションの縦長スクロール |
| CTA | 画面下部に固定。スクロール位置によらず常に出す |

**セクション構成**

| # | セクション | 役割 |
|---|---|---|
| 1 | ヒーロー | コピー「その「何となく」に、名前をつけるところから。」＋ Flourish Mapの構造図 |
| 2 | こんな状態、ありませんか | ターゲットの状態を4つ並べ、言語化できていない層に呼びかける |
| 3 | Flourish とは | 語の意味と、この製品での位置づけ。成長の4段階の図 |
| 4 | 4つの領域 | Career / Financial / Physical / Social がひとつにつながることを説明 |
| 5 | できること | 3機能を、機能名ではなく**体験の言葉**で説明 |
| 6 | はじめかた | 4ステップ。「登録は不要」「ここまで無料」を明示 |
| 7 | 大切にしていること | 何も売らない／点数をつけない／答えを押しつけない／書き換わることを歓迎する |

**機能説明の前に、言葉の意味と課題認識を置く。** いきなり機能を並べても、自分の課題を言語化できていない層には刺さらないため。

**文言のルール**

| 項目 | 決定 |
|---|---|
| CTAの文言 | **「5分で、いまの自分を見てみる」**（旧「現在地レポートを試す」） |
| CTA直下の補足 | 「登録はあとからで大丈夫です」 |
| 機能名の扱い | 「現在地レポート」「Flourish Map」「Weekly Reflection」を**ボタンや見出しに使わない**。初見では何か分からないため、体験の言葉に置き換える |

**モーション**

各セクションの要素は、スクロールに合わせて**120msずつずらして現れる**。デザイン原則 10.2 の「進んだ手ごたえ」に該当する場面であり、LPは読み物として動きを許容する。

#### 7.1.2 K-01 / K-02 記事

**公開サイト側の画面。ログイン不要で全文を読める。**

MVPで対象外にした Knowledge は「Flourish Mapの内容に応じて記事を出し分ける」機能であり、レコメンドのロジックを必要とする。**ここで作るのはカテゴリで並べるだけの公開記事**なので、その仕組みは要らない。記事の中身は1つのプールで管理し、出し分けだけを後回しにする。

**K-01 記事一覧**

| 項目 | 内容 |
|---|---|
| カテゴリ | すべて ／ Career ／ Financial ／ Physical ／ Social ／ **Flourishとは** |
| カテゴリの並び | 横スクロールのチップ。増えても縦に折り返さない |
| サムネイル | **カテゴリのアイコンを Primary Soft の面に載せた形。** 記事ごとの画像を用意しない |
| 一覧の並び | 新着順。ページングは「もっと読む」で追加読み込み |

カテゴリをサービスの4領域と揃えるのは、**読んだ人がそのまま機能の構造を理解できる**ようにするため。「Flourishとは」は考え方そのものを扱う枠として1つだけ足す。

**K-02 記事詳細**

| 項目 | 内容 |
|---|---|
| メタ情報 | カテゴリ・日付・読了時間を本文の前に置く |
| 本文 | 15px・行間1.95。読み物なのでアプリ本体（1.8）より広げる |
| CTAバナー | 末尾に置く。**記事ごとに文言を変えない**（共通バナー） |
| バナーの見た目 | Primary Soft の面に囲み、本文と地続きに見せない |
| 関連記事 | **置かない。** 読み終えた人をサービスへ向ける |
| 遷移先 | CTAバナー → S-11（現在地レポート開始） |

**ログイン状態による出し分け**

| 状態 | CTAバナー | ヘッダー右 |
|---|---|---|
| 未登録 | 表示する | ログイン |
| **ログイン済み** | **表示しない** | ホーム |

すでに使っている人に登録を勧めない。K-01 も同様にヘッダーを差し替える。

### 7.2 現在地レポート

| 画面 | 型 | 要点 |
|---|---|---|
| S-11 開始 | 読む | 下記参照 |

**S-11 の前置き**

所要時間（5分）を先に出したうえで、**考える負荷があることを隠さずに伝える**。そのうえで受け止めを添えて、身構えさせない。

> すぐには言葉にならない質問も、あるかもしれません。少し立ち止まって考えることになりますが、**そこで浮かんだことが、このあと作っていく「ありたい姿」の土台になります。**
>
> 急がなくて大丈夫です。うまく答えようとしなくても、いまの気持ちに近いところを選んでいけば進みます。

「軽く終わる」とだけ伝えると、S-14の自由記述8問で裏切られる。**先に覚悟だけ持ってもらい、同時に逃げ道も示す。**
| S-13 問い生成中 | 待ち | 「あなたに合わせた質問を用意しています」と待つ理由を書く。失敗時は S-12 へ戻す |
| S-14 自由記述 | フォーム | AIが生成した8問。**すべて任意入力**で、空欄でも進めることを冒頭で伝える。領域見出しと罫線で現在地を保つ |
| S-15 レポート生成中 | 待ち | **成功した時点でゲストセッションに保存する** |
