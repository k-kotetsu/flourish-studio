# 相談窓口の固定文面（safety_flag表示用）

> Version 1.0
> 制定：2026-08-16（P7-1）
> 参照：`10_AIプロンプト設計` 3.7、`04_画面設計` S-16、スキル`flourish-tone`
> 実装：P2-12（`web/src/views/S-16.vue`の`data-testid="safety-notice"`）

## 表示する文面

`safety_flag`が`true`のとき、S-16はあだ名・4領域の整理・言語化度／コミット度・締め・CTA（「ありたい姿を作る」）を一切表示せず、代わりに以下の文面のみを表示する。

```
書いてくださった言葉の中に、
ひとりで抱えるには重いことのように見えました。

今回は現在地レポートの代わりに、
話を聞いてくれる場所をお伝えします。


よりそいホットライン
0120-279-338（通話無料・24時間）

いのちの電話
0570-783-556（10時〜22時）
0120-783-556（毎月10日 8時〜翌日8時・通話無料）

まもろうよ こころ（厚生労働省）
電話が難しいときは、SNSでの相談窓口も探せます
https://www.mhlw.go.jp/mamorouyokokoro/


書いていただいた内容はそのまま残っています。
落ち着いたときに、あらためて見ることもできます。
```

CTA・ナビゲーション操作は置かない（P2-12完了メモの判断を踏襲。ホーム画面(S-41)自体がP4-8まで未実装のため、適切な戻り先を示せない）。

## この文面にした理由

- **診断・評価をしない。** 「〜のように見えました」と、AIの推測であることを示す言い方に留め、断定しない（flourish-tone「断定を避ける」）
- **窓口は電話2種＋SNS入口1種。** 電話が難しい利用者のための代替経路として、厚生労働省が窓口をまとめている「まもろうよ こころ」を経由先として置いた。個別のSNS相談窓口（名称・IDは変更されやすい）を直接載せず、公的機関がまとめているページへのリンクに留めることで、文面自体の陳腐化を避けた
- **入力は消えていないと伝える。** 破ってはいけない規則2「ユーザーの言葉を消さない」に対応。安全に関わる場面ほど、書いた内容が失われる不安を残さないようにした
- **感嘆符を使わない。** flourish-toneのエラー文の書き方（謝罪・感嘆符を使わない）に準じた。これはエラーではないが、同じ抑制的なトーンが適切だと判断した
- **「もう一度試す」などの再試行導線を置かない。** これは技術的な失敗ではなく、内容そのものへの応答のため、通常の生成失敗（P2-6/P2-9）とは異なる扱いにした

| 窓口 | 運営 | 選定理由 |
|---|---|---|
| よりそいホットライン | 一般社団法人 社会的包摂サポートセンター | 24時間・通話無料・自殺予防を含む生活全般の相談を受け付ける全国的な窓口 |
| いのちの電話 | 一般社団法人 日本いのちの電話連盟 | 自殺予防を目的に長年運営されている全国的な電話相談 |
| まもろうよ こころ | 厚生労働省 | SNS相談を含む相談窓口の公式な入口。個別のSNS窓口より情報が古くなりにくい |

いずれも長期間運営されている公的性格の窓口を選んだ。番号・受付時間に変更があった場合は本書を更新する。
