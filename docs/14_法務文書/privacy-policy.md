「Flourish Studio」（以下「本サービス」といいます）の運営者（以下「当社」といいます）は、利用者の情報の取り扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」といいます）を定めます。

## 1. 収集する情報

本サービスは、以下の情報を取り扱います。

| 分類 | 内容 |
|---|---|
| アカウント情報 | メールアドレス、パスワード（ハッシュ化した状態でCognitoが保持し、当社のデータベースには複製しません）、Googleアカウント連携時の認証情報 |
| ゲスト情報 | 未登録の状態で発行するCookie（`fs_guest`）。ランダムな識別子のみで、個人を特定する情報は含みません |
| セッション情報 | ログイン状態を保つためのCookie（`fs_session`）。データベースにはハッシュ化した状態で保持します |
| 現在地レポートの回答 | 選択式の質問への回答、自由記述の回答（確定した内容のみ） |
| ありたい姿・領域の理想状態・年間目標 | 対話を経て確定した内容。変更履歴も保持します |
| AIとの対話ログ | ありたい姿・領域の理想状態を作る対話でのやり取り |
| ふりかえりの回答 | 目標ごとの記録、自由記述 |
| 利用状況に関する情報 | テーマ設定（自動／ライト／ダーク） |

**入力の途中経過は保存しません。** 確定した内容だけをサーバーに送ります。

## 2. 利用目的

収集した情報は、以下の目的にのみ利用します。

- 本サービスの提供（現在地レポート、ありたい姿・領域の理想状態の言語化支援、ふりかえりの提供）
- アカウントの認証、ゲスト利用から登録利用への引き継ぎ
- 不正利用の防止（同一利用者からの短時間の大量リクエストの制限など）
- 障害発生時の原因調査

## 3. AIによる処理

本サービスは、書いていただいた内容から言葉を提案したり、整理したりするために、Amazon Bedrockを通じてAnthropic社のAIモデルを利用します。

- **送信する内容は、生成に必要な入力（自由記述の回答、対話でのやり取り、確定した成果物）に限ります。** それ以外の個人情報（メールアドレスなど）はAIモデルに送信しません
- **入力していただいた内容は、AIモデルの学習には利用されません。**
- 処理を行う国・地域は、単一の国に限定されません。複数の地域にまたがる形で処理されることがあります（利用するモデル・構成の切り替えにより変わりうるため）

## 4. Cookieの利用

本サービスは、ログイン状態の維持のためにCookieを利用します。広告のためのCookieは利用しません。

| Cookie名 | 目的 | 保持期間 |
|---|---|---|
| `fs_guest` | 未登録利用者の識別 | 30日 |
| `fs_session` | ログイン状態の維持 | 30日（利用のたびに延長） |

## 5. データの保持期間

- ゲストとしての利用データは、最後の利用から30日で削除します
- **退会いただいた場合も、アカウント情報・記録した内容を物理的には削除しません。** アクセスできない状態（論理削除）にしたうえで、保持します。これは、内面の記録を扱うサービスとして「後から見返したい」という要望に将来応えられる余地を残すための方針です
- 保持期間に定めは設けていません。保持を終了してほしい場合は、8章の連絡先までお申し出ください。個別に対応します

## 6. 第三者への提供・委託

- 本サービスの提供にあたり、以下の事業者にデータの取り扱いを委託しています

| 委託先 | 委託内容 |
|---|---|
| Amazon Web Services, Inc. | サーバー・データベースの運用、AI処理（Amazon Bedrock経由） |
| Anthropic, PBC | AIモデルによる文章の提案・整理（Amazon Bedrock経由） |
| Google LLC | Googleアカウントでのログイン連携（利用する場合のみ） |

- 法令に基づく場合を除き、本人の同意なく第三者に情報を提供しません

## 7. 安全に関する対応

書いていただいた内容から、心身の安全に関わる可能性がある表現を検知した場合、本サービスは通常の結果表示に代えて、話を聞いてくれる窓口の案内を表示します。窓口の一覧は`safety-consultation.md`のとおりです。

この検知はAIによる自動判定であり、判定を人が確認する仕組みはありません。判定が外れることもあります。

## 8. お問い合わせ・情報の開示等

保持している自分の情報の確認、訂正、削除のご希望は、本サービス内のお問い合わせ窓口までご連絡ください（**連絡先は一般公開前に確定し、本章に追記します**）。

## 9. 本ポリシーの変更

本ポリシーの内容は、必要に応じて変更することがあります。重要な変更を行う場合は、本サービス上でお知らせします。
