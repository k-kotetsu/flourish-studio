# UI実装の規則

## 原則（迷ったらここ）

1. **評価に見せない。** ゲージ・偏差値・レーダーチャート・赤信号を使わない。状態は段階で示す
2. **空白を欠落として描かない。** 未作成は**破線**。グレーアウトやエラー色にしない
3. **待ち時間にも言葉を置く。** 無言のスピナーにしない
4. **ユーザーの言葉を消さない。** 失敗・戻るで入力を消さない。破棄は必ず確認する
5. **1画面に主要アクションは1つ**
6. **装飾で意味を作らない**

## カラートークン

**要素に直接カラーコードを書かない。必ずトークン経由。**

```css
:root {
  --bg: #F8F9F6;              --surface: #FFFFFF;
  --primary: #52796F;         --primary-soft: #E2ECE7;
  --text: #202522;            --text-sub: #68736D;
  --border: #E2E6E3;
  --surface-sub: #F4F6F3;     --text-faint: #828C86;
  --control-border: #7A847E;  --primary-ink: #FFFFFF;
  --danger: #9E3520;          --warning: #7C5A12;
}
[data-theme="dark"] {
  --bg: #151A18;              --surface: #1E2522;
  --primary: #8EB7A8;         --primary-soft: #263C35;
  --text: #F1F4F2;            --text-sub: #A4AFA9;
  --border: #333D38;
  --surface-sub: #252D29;     --text-faint: #7F8A84;
  --control-border: #6E7A74;  --primary-ink: #12211B;
  --danger: #E8907B;          --warning: #D9AC61;
}
```

### `--border` と `--control-border` を混同しない

| 用途 | トークン |
|---|---|
| カードの外周、セクションの区切り線 | `--border` |
| **入力欄・ラジオ・チェックボックス・目盛りのマス** | **`--control-border`** |

`--border` は地に対して 1.19 しかなく、WCAG 1.4.11 の 3:1 を満たさない。**操作部品に使うと弱視の人が枠を見つけられない。**

### ライトモードは余裕が小さい

補足文（4.66）、Primary文字（4.60）、ボタン文字（4.86）は基準を数%上回るだけ。**これらを1段でも明るくすると基準を割る。** 変更時は必ず再計測する。

### Primary を使ってよい場所

| 使う | 使わない |
|---|---|
| 主要アクションのボタン | 見出し |
| 選択済みの目盛り・ラジオ | 本文中の強調 |
| プログレスバーの進捗部分 | カードの枠 |
| 成長段階の現在位置 | アイコンの塗り分け |
| 領域カードの選択状態 | **4領域の区別** |
| リンクテキスト | 装飾 |

**1画面に Primary が3箇所以上出たら設計を疑う。**

**4領域に固有色を割り当てない。** 区別はアイコンと英語ラベルで行う。

## タイポグラフィ

| 役割 | サイズ | ウェイト | 行間 |
|---|---|---|---|
| あだ名（S-16のみ） | 28px | 700 | 1.35 |
| 画面見出し | 20px | 700 | 1.45 |
| セクション見出し | 16px | 600 | 1.5 |
| 本文 | 15px | 400 | 1.8 |
| 補足 | 13px | 400 | 1.7 |
| ラベル | 11px | 600 | 1.4（字間 .08em） |

- 和文はシステムフォント（`Hiragino Sans` → `Noto Sans JP` → `Yu Gothic` → `sans-serif`）。**Webフォントにしない**（数MBになり初回表示が遅れる）
- 欧文（領域名）のみ **Instrument Sans**（ラテン文字サブセット）
- 見出しに `text-wrap: balance`
- 本文1行は**全角30〜35文字**を上限
- **ブラウザの文字サイズ拡大に追従すること**

## レイアウト

| 項目 | 値 |
|---|---|
| 基準幅 / 検証幅 / 最大幅 | 375px / 430px / **430px 中央寄せ** |
| 左右の余白 | 16px |
| ヘッダー高 / プログレスバー / 下部固定ボタン | 56px / 4px / 56px＋セーフエリア |
| 最小タップ領域 | **44 × 44px** |
| 角丸 | カード 9px ／ ボタン 8px ／ 入力欄 7px |
| 縦の間隔 | **6 / 10 / 14 / 18 / 24px から選ぶ** |

- 兄弟要素の間隔は `gap`。個別のマージンを積まない
- **ページ本体を横スクロールさせない。** 必要な要素だけをスクロールさせる
- **公開サイト（S-01 / K-01 / K-02）のみ例外**：最大幅960px、本文640px

## 共通コンポーネント

### ボタン

| 種類 | 見た目 | 使う場所 |
|---|---|---|
| 主要 | `--primary` 地＋`--primary-ink` | **1画面に1つ** |
| 副次 | 透明地＋`--control-border` の枠 | 主要と並べるとき |
| テキスト | 枠なし・`--text-sub` | 逃げ道 |
| 無効 | `--surface-sub` 地＋`--text-faint` | 条件未達 |

**無効ボタンは消さずに残し、押せない理由を直下に補足で置く。**

### 中断ダイアログ

「× 中断」で**必ず挟む**。**「つづける」を主ボタンにする**（誤操作で失う側を既定にしない）。
「‹ 戻る」ではダイアログを出さない。

### 生成中画面（S-13 / S-15 / S-33 / S-53 / S-62）

- インジケータ＋**何をしているかを具体的に書いた進行メッセージ**
- 失敗時は**同じ画面の中身が入れ替わる。別画面へ遷移しない**
- 再試行は手動のみ。**自動リトライしない**
- **定型文で埋めない**

### 選択肢の向き

**ポジティブを右（縦積みなら下）に。全画面で統一する。**
目盛りは両端のみラベル。導入文に「右にいくほど、満たされている状態です」を添える。

### アイコン

- **線画のみ。塗りつぶしを使わない。** 線幅1.6px（24pxグリッド）、線端・接合部は丸める
- 色は `currentColor`。**インラインSVG**（アイコンフォント・画像を使わない）
- 4領域は既製セットから選んでよい
- **成長段階（種・芽・苗・木）は描き起こす。** 4つ並べたとき成長の連続が読み取れること

### 成長段階の表示

**4つすべてを並べ、該当段階だけを `--primary` で塗る。** 1つだけ示さない。**数値を出さない。**

## ダークモード

- 既定はOS追従。手動切替はユーザー選択を優先し、アカウントに保存
- トグルは**ホーム（S-41）のヘッダー右端のみ**。自動→ライト→ダーク→自動 と循環
- ダークはライトの単純な反転にしない
- **切り替えにアニメーションを付けない**
- 初回描画のちらつき防止：`index.html` のインラインスクリプトで `prefers-color-scheme` を読み、`<html>` に属性を付けてから Vue を起動する

## モーション

> **「進んだ手ごたえ」には使う。「考えている時間」には使わない。**

| 使う | 使わない |
|---|---|
| あだ名の登場（S-16） | 自由記述の入力中 |
| 成長段階の点灯 | レポート本文を読んでいる最中 |
| ホームの立ち上がり（90msずつずらす） | エラー・失敗の表示 |
| 生成中の芽の拡縮（2.6秒周期） | 選択式に答えている最中 |
| 選択時の沈み込み | ループする装飾 |
| 画面遷移（前進＝左、戻る＝右） | |

| 項目 | 値 |
|---|---|
| 登場 / 反応 | 400〜550ms / 200ms |
| ずらし幅 | 90〜160ms |
| イージング（登場） | `cubic-bezier(.2, .85, .25, 1)` |
| イージング（跳ね） | `cubic-bezier(.34, 1.56, .5, 1)` |
| 1画面あたり | **登場アニメーションは1連鎖まで** |

`prefers-reduced-motion: reduce` では**すべて止め、最終状態を即座に表示する。透明度0のまま残さない。**

## スケルトンを使わない

長い生成には生成中画面があり、通常の取得は短い。**読み込み中は何も出さず、取得できてから描画する。**

## アクセシビリティ（WCAG 2.1 AA）

| 項目 | 基準 |
|---|---|
| 文字のコントラスト | 4.5:1（大きい文字 3:1） |
| 操作部品の枠 | 3:1（`--control-border`） |
| タップ領域 | 44 × 44px |
| フォーカス | キーボード操作時に必ず可視のリング |

**色だけで意味を伝えない。** 選択済みは色に加えて枠線も変える。エラーは色に加えて文言でも示す。
