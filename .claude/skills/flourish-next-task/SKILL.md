# 次タスクの開発フロー

`docs/12_開発計画/dev-environment.md` 5章「セッションの型」を自動化したもの。**1回の発動＝1タスク（1セッション）。** 複数タスクを連続で片付けない。

## 1. 次のタスクを探す

`docs/12_開発計画/backlog.md` を **P0 → P1 → P2 …の順**に読み、`~~**ID**~~ ✅` になっていない最初の行を探す。

担当列で分岐する：

| 担当 | 動き |
|---|---|
| **CC** | そのまま実装に進む |
| **CC＋私** | CCが用意できる部分だけ実装し、人の判断・登録が要る部分は5章の完了メモに明記して止める（チェックは入れない） |
| **私** | **実装しない。** タスク内容・完了条件・参照ドキュメントをユーザーに説明して止まる |

依存列にIDがあれば、それが全て `✅` になっているか確認する。未完了の依存があれば実装せず報告する。

## 2. 宣言する

```
PX-N を実装します。
参照：（バックログの参照列）
完了条件：（バックログの完了条件列）
依存：（確認済み、または「なし」）
```

CLAUDE.mdの「指示されていないドキュメントを先回りして読まない」に従い、**参照列にあるドキュメントの該当章だけ**を読む。画面IDが絡むタスクは `grep -rn "S-XX" docs/` で関係箇所を揃える（`dev-environment.md` 4章）。タスク内容に応じて `flourish-ui`／`flourish-api`／`flourish-data`／`flourish-ai`／`flourish-tone` を呼ぶ。

## 3. 実装する

CLAUDE.mdの「破ってはいけない規則」7つを守る。

- 仕様に書かれていないことが出てきたら**止めて聞く**（勝手に決めない）
- 仕様の矛盾を見つけたら**実装前に**報告する
- バックログ内の既存の完了メモ（P1-17・P1-18など）にある「判断の記録」の書き方を踏襲する
- UIが絡む変更は `make dev` で実際に画面を確認する

## 4. 検証する

```bash
make lint && make test
```

失敗したら原因を直して再実行する。直せない失敗（仕様不明・判断が要る）はユーザーに報告して止まる。CLAUDE.mdの規則5「AIの生成に自動リトライしない」はAI生成コンテンツについての規則であり、lint/testの再実行には適用されない。

## 5. backlog.mdを更新する

- 対象行の `**PX-N**` を `~~**PX-N**~~ ✅` に書き換える（既存のP1系タスクと同じ書式）
- 表の直後に次の段落を追加する：

  ```
  **PX-N完了メモ（YYYY-MM-DD）：** 何を作ったか一文で。

  - 触ったファイルと、そこに何を実装したか
  - 仕様と実装がズレていた点・判断が必要だった点と、その理由
  - 完了条件をどう満たしたか（テスト名など）
  ```

  文体はP1-17・P1-18の完了メモに合わせる。

## 6. コミットする

```bash
git checkout -b k-kotetsu/pX-N-<slug>
git add <変更ファイル>
git commit -m "PX-N: <タスク概要>"
```

コミットメッセージは既存の `P1-18: AppStackのLambdaに...` の書式（`PX-N: ` に続けて概要）に合わせる。

## 7. PRを作成し、CIを待つ

```bash
git push -u origin k-kotetsu/pX-N-<slug>
gh pr create --title "PX-N: <タスク概要>" --body "..."
gh pr checks <番号>
```

CIが失敗したら原因を直して追加コミットし、再度CIを確認する。**CIの結果を待たずに合否を報告しない。** 直せない失敗はユーザーに報告して止まる（マージしない）。

## 8. マージする

CIが全てpassしたら：

```bash
gh pr merge <番号> --merge --delete-branch
```

CLAUDE.mdの規則「mainへは常にPR経由。直接pushしない」「CIが通ってからマージする」を必ず守る。

## 9. 終了する

```bash
git checkout main && git pull
```

次に本スキルを呼んだときに拾うことになるID（backlog.md上で次に未完了の行）を一言で伝える。
